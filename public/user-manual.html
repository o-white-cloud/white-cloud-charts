White Cloud Charts — User Manual

A guide to creating, editing, and exporting multi-level pie charts. No technical background required.

1. Overview of the editor

When you open the chart editor, the screen is divided into three main areas:

LeftData tree
CenterLevel tabs + chart
RightProperty editor
  • Left — Data tree: Shows your chart data as a hierarchy. Each branch becomes a slice (sector) on the chart. Deeper branches appear on outer rings.
  • Center — Chart: The live preview of your pie chart. Above the chart you will see tabs for each level (ring) of the chart.
  • Right — Property editor: When you select a tree item, a sector on the chart, or a level tab, this panel shows settings you can change. Options are grouped into labeled sections (for example Label text, Typography, Ring geometry) so related fields stay together.

At the top of the screen is a toolbar with buttons for adding data, applying styles, saving, loading, and downloading:

Add root item From file Spine strokes Palettes Help Download

2. Creating a chart from a text file

The fastest way to build a chart is to paste structured text that describes your hierarchy.

Steps

  1. Click From file in the top toolbar.
  2. Paste or type your data into the text box. Each line is one item. Use spaces at the start of a line to show which item is the parent.
  3. Click Create Items. The tree and chart update immediately.

Text format

Indent child items with spaces. More spaces means deeper in the tree (further out on the chart). Lines with no leading spaces are top-level (inner ring) items. 

Animals
 Birds
  Eagle
  Robin
 Mammals
  Dog
  Cat
Reptiles
 Snake

In this example, Animals and Reptiles are on the first ring. Birds and Mammals are children of Animals on the second ring, and so on.

Tip: You can also add items one at a time with Add root item and use the tree’s own controls to add children, rename, or delete nodes.

Values (slice sizes)

Each item has a Value section in the property editor. The Inner value field controls how large the sector is relative to its siblings on the same ring. Larger values produce wider sectors. Sibling sectors on the same ring share the parent’s arc proportionally.

3. Selecting items and levels

You can select what to edit in three ways:

Select a tree item (left panel)

Click any name in the data tree. The matching sector is highlighted on the chart, and the right panel shows that item’s properties.

Select a sector on the chart (center)

Click directly on a colored slice in the chart. The corresponding tree item is selected and its properties appear on the right.

Select a level (ring)

Click a Level 1, Level 2, etc. tab above the chart. The right panel switches to level-wide settings that apply to every sector on that ring (unless overridden individually).

Tip: Level settings are great for changing font size, colors, or label style for an entire ring at once.

4. Editing properties on the right

The property editor on the right shows fields such as color, font size, label style, and stroke settings. Related options are grouped into sections — each section has a title, a short explanation at the top, and its own fields below. Under each field name you will also see a one-line description of what it does.

When a sector (tree item) is selected

The panel is organized into these sections:

  • Value — How large this slice is on its ring (Inner value).
  • Label text — Main text, label color, font size, font family, line height, and extra Text spans.
  • Label layout — How and where the label sits (Display, Anchor, Delta X, Delta Y).
  • Fill and strokes — Sector fill color, outer stroke, and start/end radius edge lines.

When a level (ring) is selected

The panel is organized into these sections:

  • Ring geometry — Inner and outer radius, start angle, pad angle, corner radius.
  • Fill — Default fill color for the ring (single color, gradient, or per-sibling colors).
  • Outer edge — Color and thickness of the border along the outside of each sector.
  • Label layout — Default label placement for the whole ring, plus Center all sector text.
  • Typography — Default fonts, Reset span sizes to inherit / Reset span fonts to inherit, and Text line height.
  • Stroke — Default outline around each sector on the ring.
  • Sector values — Equalize sector values to make every slice on the ring the same size.

Three ways a property can be set

When editing an individual sector (tree item), you may see a small dropdown next to each property:

Setting What it means
Level Use the value defined for the entire ring (level). Changes to the level affect this sector automatically.
Parent Use the value from the parent sector. Useful when children should match their parent’s style.
Override Set a custom value for this sector only. Other sectors are unaffected.

To override a property, choose Override ▾ in the dropdown (or simply change the value — this usually switches to Override automatically). To go back to shared settings, choose Level or Parent again.

Common properties

  • Color — Fill color of the sector (in Fill and strokes for a sector, or Fill for a level).
  • Display — How text is drawn (see next section). Found under Label layout.
  • Label color / Font size / Font family — Typography for this sector’s main label. Found under Label text.
  • Delta X / Delta Y — Fine-tune label position (horizontal and vertical offset). Found under Label layout.
  • Stroke width / Stroke color — Outline around the sector.
  • Start / end radius stroke — Lines along the leading or trailing radial edge of a slice (sector editor, Fill and strokes section).
  • Level thickness (level only) — Inner and outer radius of the ring (Ring geometry section).
  • Equalize sector values (level only) — In the Sector values section; click Equalize sector values to make all sectors on that ring the same size and adjust parent levels accordingly.

5. Text labels on sectors

Each sector can show a label — usually the item name. You control how that text is placed using Display under the Label layout section in the property editor.

Centroid

Text sits at the geometric center of the slice. Best for short labels on medium-sized sectors. Use Delta X and Delta Y (in Label layout) to nudge the text horizontally and vertically.

Radial

Text is rotated to follow the direction of the slice, like spokes on a wheel. Good for labels that should read along the radius. Position offsets still apply.

Path

Text follows the curved arc of the slice, bending along the ring. Ideal for longer labels on outer rings. The text flows along the inner curve of the sector.

Label anchor

For centroid and radial labels, Anchor (in Label layout) controls alignment: start (left), middle (center), or end (right) relative to the label position.

Center all sector text (level editor)

When editing a level, open the Label layout section and click Center all sector text to automatically center centroid and radial label blocks on every sector on that ring. Run it again after you change text or spans.

6. Splitting text into spans

Sometimes one label needs multiple lines or differently styled pieces — for example a title and a subtitle, or numbers in a different color. You can split the main text into spans.

Split main text into lines

  1. Select a sector and open the Label text section in the property editor.
  2. Find Main text and click the split-lines button next to the text field:
Main text
Revenue

The rows icon splits main text into spans. The fold icon appears when spans exist and merges them back.

  1. In the dialog, type or paste your text with line breaks. The first line becomes the main text; each additional line becomes its own span, stacked below using the text line height.
  2. Click Create spans.

Text spans section

In the same Label text section, below main text, you will see Text spans. Each span is an extra piece of label text. Click to add a span manually. Click a span to expand it and edit:

  • Text — The characters shown.
  • Color — Text color for this span only.
  • Font — Shows the inherited font family from the sector or level. Click to override with a custom font; click to inherit again.
  • Font size — Same pattern as font family: inherited value by default, with an icon to override or restore inheritance.
  • Font weight — Normal, bold, etc.
  • Position (x, y, dX, dY) — Place the span relative to the label anchor. dX and dY are small shifts; x and y set absolute offsets when you need precise placement.
  • Anchor — How this span aligns (start, middle, end).

7. Spine strokes

In a multi-level chart, a “spine” is the line running through the middle of a branch — from a top-level sector down through its first child, first grandchild, and so on. These connected wedges can be hard to see when slices are similar colors.

Spine strokes adds a visible line along the inner (start-radius) edge of that chain so the branch reads as one connected wedge.

How to use it

  1. Click Spine strokes in the top toolbar.
  2. Enter a Start radius stroke width (for example 2). This is the thickness of the line in pixels.
  3. Click Apply.

The tool walks each top-level sector and applies the stroke along the first-child chain only (not sibling branches). You can still adjust start-radius stroke color per sector in the Fill and strokes section of the property editor if needed.

8. Color palettes

Palettes give your chart a coordinated set of colors without picking each sector by hand.

Applying a palette

  1. Click Palettes in the top toolbar.
  2. Browse the available palettes (for example Soft Pastel, Vibrant, Earth tones).
  3. Click a palette to preview it on your chart immediately.
  4. Click Apply on the palette you want to keep. This saves your color choice with the chart.
  5. Click Cancel to close without applying — your chart reverts to how it looked before you opened the dialog.

Palettes assign colors to top-level sectors and automatically shade child sectors so related branches stay visually connected. Text colors are adjusted for readability on each background.

Tip: After applying a palette you can still override individual sector colors using Override ▾ in the property editor.

9. Saving and loading your work

Your chart — tree structure, levels, colors, labels, and all settings — can be saved as a JSON file so you can reopen it later or share it with colleagues.

Save (export JSON)

  1. Click the save button in the toolbar:
  2. Enter a file name (for example my-chart). The file will be saved as my-chart.json.
  3. Confirm. The file downloads to your computer.

Load (import JSON)

  1. Click the upload button in the toolbar:
  2. Choose a .json chart file you saved earlier.
  3. The editor replaces the current chart with the loaded data.
Tip: Save your work regularly. Loading a file replaces everything currently on screen, so save first if you want to keep your current chart.

10. Downloading as SVG

When your chart is ready for a report, presentation, or print, export it as an SVG image — a high-quality vector format that scales without losing sharpness.

Steps

  1. Click Download on the right side of the toolbar.
  2. Enter a file name (for example chart). The file will be saved as chart.svg.
  3. Confirm. The SVG file downloads to your computer.

The exported SVG includes your chart geometry, colors, strokes, and text. Fonts used in labels are embedded so the file looks correct when opened in browsers, design tools, or document editors that support SVG.

Workflow summary: Build your chart → save JSON to preserve your editable project → download SVG when you need the final image.
